# B-3 테스트 씬 구성 가이드

목표: **두 인스턴스에서 서로의 캐릭터가 부드럽게 움직이는 것**을 확인한다.

---

## 1. 플레이어 프리팹 만들기

**Hierarchy 우클릭 → 3D Object → Capsule** → 이름을 `NetPlayer`로 변경

Inspector에서 **Add Component**로 셋을 붙인다:

| 컴포넌트 | 역할 |
|---|---|
| `NetIdentity` | netId·소유자 신분증 |
| `NetTransform` | 위치 전송 + 보간 |
| `TestPlayerController` | WASD 조작 (소유자만) |

> `TestPlayerController`를 먼저 붙이면 `NetIdentity`는 자동으로 따라옵니다.

**프리팹으로 저장:** `Assets/Prefabs/` 폴더에 드래그 → 씬에 남은 원본은 **삭제**

## 2. 바닥 만들기 (선택이지만 권장)

**Hierarchy 우클릭 → 3D Object → Plane** → Scale을 `(2, 1, 2)` 정도로

없어도 동작하지만, 바닥이 있어야 움직임이 눈에 잘 들어옵니다.

## 3. NetTest 오브젝트에 NetWorld 추가

기존 `NetTest` 오브젝트(NetManager + NetTestUI가 붙어 있는 것)를 선택 →

**Add Component → NetWorld**

그리고 Inspector에서:

```
Prefabs  →  Size: 1
            Element 0: NetPlayer   ← 방금 만든 프리팹을 드래그
```

⚠️ **배열 순서가 곧 `prefabId`입니다.** 나중에 젤리·봇을 추가할 때 **뒤에만 덧붙이고**, 중간에 끼워넣지 마세요. 순서가 바뀌면 양쪽 해석이 어긋납니다.

## 4. 카메라 위치

기본 카메라는 캐릭터를 못 볼 수 있습니다. `Main Camera`를 이렇게 두면 전체가 보입니다:

```
Position: (0, 12, -10)
Rotation: (45, 0, 0)
```

---

## 5. 실행

**Multiplayer Play Mode**로 플레이어 2명을 띄우고:

1. 한쪽 → **[호스트 시작]** → 캡슐 1개가 생기고 **초록색**(내 것)
2. 다른 쪽 → **[참가]** (`127.0.0.1`) → 캡슐 2개
   - 자기 캡슐 = 초록
   - 호스트 캡슐 = 회색
3. 각자 **WASD**로 움직여 보기

### 확인할 것

| 항목 | 기대 결과 |
|---|---|
| 스폰 복제 | 양쪽 화면에 캡슐이 **같은 개수** |
| 소유권 | **내 키보드는 내 캡슐만** 움직인다 |
| 위치 동기화 | 상대 캡슐이 내 화면에서도 움직인다 |
| **늦은 입장** | 나중에 들어온 사람도 **기존 캡슐이 다 보인다** |
| 퇴장 정리 | 한쪽이 나가면 그 캡슐이 **사라진다** |

## 6. 보간 비교 — B-3의 핵심 실험

로컬에서는 지연이 0.1ms라 **보간이 없어도 멀쩡해 보입니다.** 그래서 일부러 지연을 겁니다.

```
① UI에서 [원격] 프리셋 클릭  (편도 30ms, 양쪽에 켜면 RTT 60ms)
② 상대가 계속 움직이는 상태에서
③ 보간 모드를 바꿔가며 관찰
```

| 모드 | 보이는 현상 |
|---|---|
| **없음** | 50ms마다 **뚝뚝 순간이동**. 실제 게임이면 못 봐줄 수준 |
| **Lerp** | 부드럽지만 **항상 조금 뒤처지고**, 방향을 꺾으면 미끄러짐 |
| **스냅샷** | 부드럽고 궤적도 정확. 대신 `InterpDelay`만큼 늦게 재생 |

**이 차이를 눈으로 확인하는 것이 B-3에서 가장 중요한 부분입니다.**

`InterpDelay` 슬라이더도 바꿔보세요:
- 너무 작으면(20ms) → 데이터가 늦게 오는 순간 끊김이 생김
- 너무 크면(400ms) → 부드럽지만 반응이 눈에 띄게 늦음
- **전송 간격(50ms)의 2배쯤이 적당** → 기본값 100ms

## 자주 겪는 문제

| 증상 | 원인 |
|---|---|
| 캡슐이 안 생김 | `NetWorld`의 `Prefabs` 배열이 비었거나 프리팹에 `NetIdentity`가 없음 |
| 내 키보드가 상대 캡슐도 움직임 | `NetIdentity.IsMine` 가드가 빠짐 — 스크립트 확인 |
| 상대 캡슐이 안 움직임 | 상대 쪽에서 위치를 안 보내는 중. `NetTransform`이 붙었는지 확인 |
| 늦게 들어온 사람이 빈 화면 | 늦은 입장 스냅샷 문제 — `HandlePeerJoined` 확인 |
| 캡슐이 바닥을 뚫고 떨어짐 | Capsule에 Rigidbody가 붙어 있으면 제거 (지금은 물리 없이 이동) |
