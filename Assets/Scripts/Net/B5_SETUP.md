# B-5 밀치기 모드 (5-1 · 5-2) — 씬 구성 가이드

목표: **스페이스로 상대를 밀어내고, 그 결과가 모든 화면에서 같게 보이는 것.**

---

## 1. 플레이어 프리팹에 `NetKnockback` 추가

`NetPlayer` 프리팹 → **Add Component → NetKnockback**

```
Damping     4      (밀린 속도가 줄어드는 비율)
Stop Speed  0.05
```

`TestPlayerController`에 항목이 하나 늘었습니다:

```
Control While Pushed  0.3   ← 밀리는 동안 조작이 30%만 먹힘
```

0으로 두면 완전 경직, 1이면 밀려도 자유롭게 움직입니다. **0.3이면 넉백이 눈에 확실히 보입니다.**

## 2. `NetTest` 오브젝트에 `PushMode` 추가

**Add Component → PushMode**

```
Attack Key       Space
Bat Range        1.6    (내 크기에 비례해 늘어남)
Bat Push Force   8
Bat Cooldown     0.5    (호스트가 강제)
Bat Hit Growth   0.06
Range Tolerance  1.6    (호스트 재검증 여유)
```

> 젤리가 방해되면 `AbsorbMode`의 **`Spawn Jelly` 체크를 꺼두세요.** 두 모드가 지금은 동시에 돌아갑니다(모드 분리는 4-4·5-4에서).

## 3. 실행 & 확인

1. 양쪽 접속 → 캡슐 두 개를 **가까이** 붙임
2. 한쪽에서 **스페이스**
3. 상대 캡슐이 **밀려남**

### 확인 항목

| 항목 | 기대 결과 |
|---|---|
| 넉백 방향 | 때린 쪽에서 **멀어지는 방향** |
| 양쪽 화면 일치 | 밀려나는 모습이 **두 화면에서 같게** |
| 쿨다운 | 스페이스 연타해도 **0.5초에 한 번**만 |
| 사거리 | 멀리서 누르면 **아무 일도 안 일어남** |
| 성장 | 때린 쪽 크기가 **조금 커짐** (UI에서 확인) |

로그도 확인하세요:

```
[호스트] P1 → P2 배트 히트!
[P2쪽]   밀려남! (힘 8.0)
```

## ★ 이번 단계의 핵심 — 넉백은 **한 명에게만** 갑니다

흡수 때는 결과를 전원에게 방송했지만, 넉백은 다릅니다.

```
흡수 확정  →  전원에게 방송 (Broadcast)
넉백       →  피격자 소유자에게만 (SendTo)   ← 왜?
```

**피격자는 이미 자기 위치를 초당 20번 보내고 있습니다.** 그 사람만 밀려나면, 결과가 `TransformUpdate`를 타고 자동으로 전원에게 퍼져요.

전원에게 넉백을 보내면 이렇게 됩니다:

```
① 각자 자기 화면에서 피격자를 밀어냄        ← 계산 중복
② 그 위에 소유자가 보낸 진짜 위치가 덮어씀  ← 충돌 → 덜덜 떨림
```

**"권위 있는 한 명만 움직이고, 나머지는 결과만 본다."**

이건 Photon판에서 `RpcTarget.All`이 아니라 `victimPV.Owner`를 쓴 것과 정확히 같은 판단이고, 기술명세서의 "RpcTarget 선택 근거"에 적어둔 내용이기도 합니다.

## 호스트가 검증하는 5가지

클라의 "때렸다"는 주장을 **그대로 믿지 않습니다.**

| 검사 | 막는 것 |
|---|---|
| 소유권 | 남의 캐릭터를 내세운 요청 |
| 같은 편 | 자기 자신·아군 타격 |
| 대상 종류 | 젤리를 때려서 성장 |
| **쿨다운** | 요청 연사로 무한 성장 |
| **거리 재검증** | 맵 반대편 상대를 밀어내기 |

쿨다운을 **클라가 아니라 호스트가** 재는 게 핵심입니다. 클라 쪽 쿨다운(`_localCooldown`)은 그냥 UX용이라 조작하면 무력화되거든요.

## 자주 겪는 문제

| 증상 | 원인 |
|---|---|
| 스페이스를 눌러도 아무 일 없음 | 사거리 밖. 캡슐을 더 붙이세요 |
| 밀려나긴 하는데 상대 화면엔 안 보임 | 피격자에게 `NetKnockback`이 없음 |
| 내가 밀리는데 조작이 그대로 먹힘 | `Control While Pushed`가 1에 가까움 |
| 밀림이 뚝뚝 끊김 | 정상 — 20Hz 위치 전송 + 보간. `[원격]` 프리셋 켜면 더 뚜렷 |
| 때려도 안 커짐 | 프리팹에 `NetScale` 누락 |
